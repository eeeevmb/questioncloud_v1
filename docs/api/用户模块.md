# 用户模块 API
## 用户注册
### 请求路径
```http
POST /api/v1/user/register
```

### 简要说明
> 用户注册账号接口
>

### 请求头
| **名称** | 示例值 | **必选** | **说明** |
| --- | --- | --- | --- |
| Content-Type | application/json | 是 | 请求体格式(json) |


### 请求体
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| username | string | 是 | 用户名，长度 3–16；允许中文、字母、数字、下划线 _、连字符 - |
| email | string | 是 | 邮箱，需为合法邮箱格式 |
| password | string | 是 | 密码，长度 8–20；需至少包含以下类型中的两种：大写字母、小写字母、数字、特殊字符（@$!%*?&#.） |


### 路径参数
无

### 查询参数
无

### 请求示例
```json
POST /api/v1/user/register HTTP/1.1
Content-Type: application/json

{
  "username": "dev01",
  "email": "dev01@example.com",
  "password": "Abcdef12@"
}
```

### 成功响应示例
```json
{
    "code": "200000",
    "message": "请求成功",
    "data": {
        "userId": "148147932019818497"
    }
}
```

## 用户登出
### 请求路径
```http
POST /api/v1/user/logout
```

### 简要说明
> 用户登出账号接口，需要登陆（Sa-Token）
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=9807c27.. | 是 | 登陆态凭证，包含<font style="background-color:rgba(255, 255, 255, 0);">satoken=<token></font> |
| Content-Type | application/json | 否 | 本接口无请求体，仅为统一规范可携带 |


### 请求体
无

### 路径参数
无

### 查询参数
无

### 请求示例
```json
POST /api/v1/user/logout HTTP/1.1
Cookie: satoken=9807c278-9d2d-4e7c-9aa5-ad3732823df7
Content-Type: application/json
```

### 成功响应示例
```json
{
    "code": "200000",
    "message": "请求成功",
    "data": null
}
```

## 用户上传头像
### 请求路径
```http
POST /api/v1/user/avatar
```

### 简要说明
> 用户上传头像接口，需要登陆（Sa-Token）
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=0b36... | 是 | 登陆态凭证 |
| Content-Type | multipart/form-data | 是 | 请求体格式 |


### 请求体
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| file | file（multipart file） | 是 | 图片文件，字段名必须是file |


### 路径参数
无

### 查询参数
无

### 请求示例
```json
POST /api/v1/user/avatar HTTP/1.1
Cookie: satoken=0b36c8cc-6460-479b-9e9a-d8b4aedd14fc
Content-Type: multipart/form-data; boundary=<calculated when request is sent>

--<boundary>
Content-Disposition: form-data; name="file"; filename="fig1.png"
Content-Type: image/png

<文件内容省略>
--<boundary>--
```

### 成功响应示例
```json
{
    "code": "200000",
    "message": "请求成功",
    "data": {
        "url": "128241268605059073/2026-08/0655448b-9b46-4ed6-a665-e006965531ed.png"
    }
}
```

## 查看头像
### 请求路径
```http
GET /api/v1/user/avatar/{userId}
```

### 简要说明
> 获取指定用户头像图片。若未设置头像或无当前用户，返回默认头像
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Accept | image/* | 否 | 期望返回图片类型 |


### 请求体
无

### 路径参数
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| userId | string/number | 是 | 用户ID |


### 查询参数
无

### 请求示例
```http
GET /api/v1/user/avatar/1 HTTP/1.1
Accept: image/*
```

### 成功响应示例
```http
HTTP/1.1 200 OK
Content-Type: image/png   // 或 image/jpeg，取决于实际头像格式
Cache-Control: public, max-age=2592000

<binary image data>
```
