# 文件模块 API
## 文件上传
### 请求路径
```http
POST /api/v1/common/file
```

### 简要说明
> 文件上传接口，目前主要用于上传题目附图与批量导入模板，返回文件ID。需要登录（Sa-Token）
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=8cb94.. | 是 | 登录态凭证 |
| Content-Type | multipart/form-data | 是 | 请求体格式 |


### 请求体
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| file | file（multipart file） | 是 | 文件，字段名必须是file |


### 路径参数
无

### 查询参数
无

### 请求示例
```http
POST /api/v1/common/file HTTP/1.1
Cookie: satoken=8cb941b3-93b5-4f5f-9fb6-feb705d82dde
Content-Type: multipart/form-data; boundary=<calculated when request is sent>

--<boundary>
Content-Disposition: form-data; name="file"; filename="fig2.png"
Content-Type: image/png

<文件内容省略>
--<boundary>--
```

### 成功响应示例
```json
{
    "code": "200000",
    "message": "请求成功",
    "data": {
        "fileId": "14"
    }
}
```

## 图片文件预览
### 请求路径
```http
GET /api/v1/common/file/{fileId}/view
```

### 简要说明
> 图片文件预览接口，目前主要用于查看题目附图。
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Accept | image/* | 否 | 期望返回图片类型 |


### 请求体
无

### 路径参数
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| fileId | string/number | 是 | 文件ID |


### 查询参数
无

### 请求示例
```http
GET /api/v1/common/file/14/view HTTP/1.1
Accept: image/*
```

### 成功响应示例
```json
HTTP/1.1 200 OK
Content-Type: image/png   // 或 image/jpeg，取决于实际图片格式
Cache-Control: private, max-age=604800

<binary image data>
```
