## 创建导入请求
### 请求路径
```http
POST /api/v1/imports
```

### 简要说明
> 创建导入请求接口。需要登录（Sa-Token）
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=8cb94.. | 是 | 登录态凭证 |
| Content-Type | application/json | 是 | 请求体格式 |


### 请求体
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| fileId | string/number | 是 | 上传文件接口返回的ID |
| format | string | 是 | 文件格式，目前仅支持excel |


### 路径参数
无

### 查询参数
无

### 请求示例
```http
POST /api/v1/imports HTTP/1.1
Cookie: satoken=8cb941b3-93b5-4f5f-9fb6-feb705d82dde
Content-Type: application/json

{
    "fileId": 17,
    "format": "excel"
}
```

### 成功响应示例
```json
{
    "code": "200000",
    "message": "请求成功",
    "data": {
        "importId": "152468539805007873",
        "parseJobId": "152468539805007873"
    }
}
```

## 查询导入进程详情
### 请求路径
```http
GET /api/v1/imports/{importId}
```

### 简要说明
> 查询导入进程详情接口。需要登录（Sa-Token）
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=8cb94.. | 是 | 登录态凭证 |
| accept | application/json | 否 | 期望响应格式 |


### 请求体
无

### 路径参数
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| importId | string/number | 是 | 导入会话ID |


### 查询参数
无

### 请求示例
```http
GET /api/v1/imports/152468539805007873 HTTP/1.1
Cookie: satoken=8cb941b3-93b5-4f5f-9fb6-feb705d82dde
```

### 成功响应示例
```json
{
    "code": "200000",
    "message": "请求成功",
    "data": {
        "importId": "152468539805007873",
        "status": 1,
        "total": 13,
        "validCnt": 10,
        "invalidCnt": 3,
        "progress": 1.0000
    }
}
```

#### 字段说明
| **字段名** | **类型** | **说明** |
| --- | --- | --- |
| status | number | 导入会话状态<br/>0=**PARSING**, 1=**READY**, 2=**COMMITTING**,<br/>3=**COMMITTED**, 4=**CANCELED**, 5=**FAILED** |
| total | number | 识别题目总数 |
| validCnt | number | 合法题目数量 |
| invalidCnt | number | 非法题目数量 |
| progress | number | 题目解析进度 |

## 题目草稿更新
### 请求路径
```http
PUT /api/v1/imports/{importId}/items
```

### 简要说明
> 题目草稿更新接口。需要登录（Sa-Token）
>
> **<font style="color:#0e0e0e;">注：这是覆盖式更新</font>**<font style="color:#0e0e0e;">。在更新草稿时，要把该草稿完整字段都传回去（哪怕是 null 或 []），否则会把原值覆盖。</font>
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=8cb94.. | 是 | 登录态凭证 |
| Content-Type | application/json | 是 | 请求体格式 |


### 请求体
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| items | array<Item> | 是 | 要更新的草稿列表 |


#### Item字段
| **字段名** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| itemId | number(long) | 是 | 草稿记录 ID |
| draft | QuestionDraft | 是 | 草稿内容（完整覆盖更新） |


#### QuestionDraft字段
| **字段名** | **类型** | **必选** | **说明** | **备注** |
| --- | --- | --- | --- | --- |
| typeCode | string | 是 | 题型编码 | 例如：single-choice / multiple-choice / fill-in / true-false / short-answer |
| title | string | 否 | 标题 | 可不填 |
| stem | string | 是 | 题干 |  |
| options | array<QuestionOption> | 否 | 选项列表 | 非选择题可传 [] |
| answer | string | 否 | 答案展示/填写 | 可不填 |
| correctOptions | array<string> | 是 | 正确选项 key 列表 | 单选如 ["A"]；多选如 ["B","C","E"] |
| judgeAnswer | string | 是 | 判断题答案 |  "T" / "F" |
| solution | string | 否 | 解析 | 可不填 |
| difficulty | number(decimal) | 是 | 难度系数 | 取值: [0.00, 1.00] |


#### QuestionOption字段
| **字段名** | **类型** | **可为空** | **说明** | **示例** |
| --- | --- | --- | --- | --- |
| key | string | 是 | 选项标识 | "A" / "B" / "C" / "D" |
| content | string | 是 | 选项内容（文本或 LaTeX） | "$\\frac{1}{2}$" |


### 路径参数
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| importId | string/number | 是 | 导入会话ID |


### 查询参数
无

## 分页查询题目草稿
### 请求路径
```http
GET /api/v1/imports/{importId}/items
```

### 简要说明
> 分页查询题目草稿，可按草稿状态筛选。需要登录（Sa-Token）
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=8cb94.. | 是 | 登录态凭证 |
| accept | application/json | 否 | 期望响应格式 |


### 请求体
无

### 路径参数
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| importId | string/number | 是 | 导入会话 ID |


### 查询参数
| **名称** | **类型** | **必选** | **默认值** | **说明** | **约束/备注** |
| --- | --- | --- | --- | --- | --- |
| pageNum | number(int) | 否 | 1 | 页码（从 1 开始） | <1 会被自动修正为 1 |
| pageSize | number(int) | 否 | 20 | 每页条数 | <1 会被自动修正为 20 |
| status | string | 否 | ALL | 草稿状态 | 取值: VALID /INVALID/ALL |


### 请求示例
```http
GET /api/v1/imports/152468539805007873/items?status=VALID HTTP/1.1
Cookie: satoken=8cb941b3-93b5-4f5f-9fb6-feb705d82dde
Accept: application/json
```
