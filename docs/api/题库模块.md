# 题库模块 API
## 题目创建
### 请求路径
```http
POST /api/v1/question
```

### 简要说明
> 题目创建接口。需要登录（Sa-Token）
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=8cb94.. | 是 | 登录态凭证 |
| Content-Type | application/json | 是 | 请求体格式 |


### 请求体
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| typeCode | string | 是 | 题目类型编码，见下表 |
| title | string | 否 | 题目标题 |
| stem | string | 是 | 题干，可含LaTeX数学公式 |
| options | array<QuestionOption> | 否 | 选项列表（选择题适用） |
| answer | string | 否 | 答案展示字段，可含LaTeX数学公式 |
| correctOptions | array<string> | 否 | 正确选项<br/>必须在选项列表里 |
| judgeAnswer | string | 否 | 判断题答案<br/>必须为 **T** 或者 **F** |
| solution | string | 否 | 题目解析，可含LaTeX数学公式 |
| difficulty | number | 是 | 难度系数<br/>取值范围：**[0.00–1.00]** |
| collectionId | string/number | 是 | 题集 ID |
| assets | array<QuestionAsset> | 否 | 题目/解析附图 |


#### 题目类型
| **类型编码** | **题型名称** |
| --- | --- |
| single-choice | 单选题 |
| multiple-choice | 多选题 |
| true-false | 判断题 |
| fill-in | 填空题 |
| short-answer | 简答题 |


> 题型编码必须为上述枚举之一
>

#### 选项元素
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| key | string | 是 | 选项，如A/B/C |
| content | string | 是 | 选项内容，可含LaTeX数学公式 |


> <font style="color:#0e0e0e;">选择题每个选项都必须包含 key 与 content</font>
>
> <font style="color:#0e0e0e;">单选题只能有一个正确选项，多选题至少要有一个正确选项</font>
>

#### <font style="color:#0e0e0e;">附件元素</font>
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| fileId | string/number | 是 | 文件 ID（来自文件上传接口返回） |
| section | string | 是 | 图片出现位置<br/>"PRO"（题干）/ "SOLU"（解析） |
| ordinal | number | 是 | 在该 section 内出现顺序 |


### 路径参数
无

### 查询参数
无

### 请求示例
#### 选择题
**请求体**

```http

  "title": "例题",

  "answer": "\\frac{1}{6} - \\frac{1}{3e}",
  "solution": "设积分区域 $D: 0 \\leq y \\leq 1,\\ 0 \\leq x \\leq y$，则二重积分可化为累次积分：\n\\begin{align*}\nI &= \\int_{0}^{1} e^{-y^{2}} \\, dy \\int_{0}^{y} x^{2} \\, dx \\\\\n&= \\int_{0}^{1} e^{-y^{2}} \\left( \\left. \\frac{1}{3}x^{3} \\right|_{0}^{y} \\right) dy \\\\\n&= \\frac{1}{3} \\int_{0}^{1} y^{3} e^{-y^{2}} \\, dy \\\\\n&= \\frac{1}{3} \\left[ \\left. -\\frac{1}{2} y^{2} e^{-y^{2}} \\right|_{0}^{1} + \\int_{0}^{1} y e^{-y^{2}} \\, dy \\right] \\\\\n&= \\frac{1}{6} \\left[ -\\left( 1 \\cdot e^{-1} - 0 \\right) + \\left. \\left( -\\frac{1}{2} e^{-y^{2}} \\right) \\right|_{0}^{1} \\right] \\\\\n&= \\frac{1}{6} - \\frac{1}{3e}\n\\end{align*}",
  "difficulty": 0.50,
  "collectionId": "128241268747665408"
}
```

## 分页查询题集内题目概要
### 请求路径
```http
GET /api/v1/collection/{collectionId}/questions
```

### 简要说明
> 分页查询指定题集下的题目概要列表，可按题型、难度区间筛选。需要登录（Sa-Token）
>

### 请求头
| **名称** | **示例值** | **必选** | **说明** |
| --- | --- | --- | --- |
| Cookie | satoken=8cb94.. | 是 | 登录态凭证 |
| Accept | application/json | 否 | 期望返回类型 |


### 请求体
无

### 路径参数
| **名称** | **类型** | **必选** | **说明** |
| --- | --- | --- | --- |
| collectionId | string/number | 是 | 题集 ID |


### 查询参数
| **名称** | **类型** | **必选** | **默认值** | **说明** | **约束/备注** |
| --- | --- | --- | --- | --- | --- |
| pageNum | number(int) | 否 | 1 | 页码（从 1 开始） | <1 会被自动修正为 1 |
| pageSize | number(int) | 否 | 20 | 每页条数 | <1 会被自动修正为 20 |
| keyword | string | 否 | - | 标题关键词<br/>(like 匹配) | 长度 ≤ 50（超出抛参数错误） |
| sortField | string | 否 | - | 排序字段 | 字段见下表 |
| sortDirection | string | 否 | DESC | 排序方向 | ASC/DESC<br/>非法值修正为DESC |
| typeCode | string | 否 | - | 题型编码 | 见题型枚举 |
| levelMin | number(decimal) | 否 | - | 难度下限 | 取值范围 **[0.00–1.00]** |
| levelMax | number(decimal) | 否 | - | 难度上限 | 取值范围 **[0.00–1.00]** |


#### sortField 可选值
| **sortField** | **含义** | **对应字段** | **备注** |
| --- | --- | --- | --- |
| createdAt | 创建时间 | QuestionEntity.createdAt | 支持 ASC/DESC |
| updatedAt | 更新时间 | QuestionEntity.updatedAt | 支持 ASC/DESC |
| difficulty | 难度系数 | QuestionStat.difficulty | 支持 ASC/DESC |
